# Portfolio Case Study Formats

Use these formats across the Projects section.

The portfolio has three project types:

1. **System Case Study** — deep, strategic work
2. **Product Story** — products designed and built end-to-end
3. **Interaction Study** — focused pieces of interaction, motion, or UI craft

All project pages should follow the same basic philosophy:

**Show the work → explain the decision → show how it behaves → explain what changed.**

Avoid generic UX-process headings such as:

* The Problem
* Research
* Personas
* Wireframes
* Ideation
* Final Solution

Use headings that describe the actual story of the project.

# Summary

Symbiotique is the design system supporting MRCL's growing product ecosystem.

My role expanded beyond creating components. I worked across product design, interaction patterns, responsive behaviour, accessibility, governance, and implementation to help the system scale alongside increasingly complex AI-driven experiences.

The challenge was not simply creating consistency. It was creating enough structure for teams to move quickly without limiting what emerging AI experiences could become.

# Use Media Aggressively

Do not create walls of text.

Aim roughly for:

**visual → short explanation → visual → short explanation**

For interaction studies, every major section should ideally have:

* GIF
* video
* interactive demo
* screenshot
* before/after

The visitor should be able to understand the project even if they skim the words.

Use short paragraphs.

Usually:

* drove synergies

* utilized

* we needed
* this changed
* the interaction

# Portfolio Reading Depth

Design the portfolio so visitors can choose how deep they want to go.

### 10 seconds

Project image + title + proposition.

### 30 seconds

Metadata + proof points + major headings.

### 2 minutes

Visuals + section summaries.

### 5+ minutes

Full narrative for the larger projects.

Only Symbiotique needs to be a genuinely deep case study.

CalyPad and Deska should be medium-depth product stories.

lululemon and MRCL interaction studies should be short and extremely visual.
